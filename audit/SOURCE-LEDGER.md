# Historical evidence ledger

This ledger records editorial decisions made on 8 October 2026. It is an evidence-status record, not a claim that every item has been checked against a manuscript. The cloud proxy returned HTTP 403 for both the published site and the Maharashtra Gazetteers website. Source-level online checks, folio/page verification, and image rights revalidation remain open.
